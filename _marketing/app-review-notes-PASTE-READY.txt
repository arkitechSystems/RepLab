ACCOUNT DELETION (Guideline 5.1.1(v))
Path: Profile tab > Delete Account button (below Sign Out).
Confirmation: user re-enters their account password AND types the literal word DELETE into the confirmation field.
Effect: immediate hard delete with CASCADE across 24 dependent tables (programs, templates, sessions, personal bests, schedule, metrics, feedback, subscriptions, push tokens, etc.). Custom exercises the user authored are anonymized (created_by set to NULL) rather than deleted, since other users may have copied them into templates.
Endpoint: DELETE /auth/delete-account (password-verified).

A full JSON data export is also available from the same screen via GET /auth/export-data.

IOS PAYMENTS (Guideline 3.1.1)
REPLAB v1 ships free-tier-only on iOS. All Stripe checkout paths are hidden when Capacitor.getPlatform() === 'ios'. The /upgrade screen renders informationally so iOS users can see what Pro and Elite contain, but no purchase or subscribe button is exposed. The AI Workout Generator is a Pro feature and therefore not reachable from the iOS Free build. In-app purchase via StoreKit is planned for a subsequent release.
