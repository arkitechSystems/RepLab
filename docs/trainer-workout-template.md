# Trainer workout & program template (Excel / Google Sheets → Trainer Central)

A spreadsheet trainers fill out in Excel or Google Sheets to build a single workout or a full
program, then upload in Trainer Central; the app converts it into a workout (template) or a
program they can assign to clients or themselves. Later, a "Create a Workout / Program" web page
in Trainer Central will do the same thing online. Started 2026-10-11 with Will.

## THE SYNC RULE (Will, 2026-10-11) — read before changing any of these

These must always stay in sync, so a filled-out sheet can simply be uploaded into the app:

1. **The spreadsheet template** — generated by `server/scripts/build-workout-template.mjs`
   → `trainer-template/RepLab-Workout-Template.xlsx` (the Google Sheets copy on
   replab-fitness.com is made from it).
2. **The app's workout fields** — what a workout / workout session / Create Workout / Edit Workout
   page can hold: exercises (library id or custom name), section headers + section notes,
   superset labels, set types, sets, goal reps (`plannedReps`), goal weight (`suggestedWeight`),
   rep range, coach notes; programs: name, description, program type, weeks of 7 days incl. rest.
3. **The upload importer** in Trainer Central (not built yet).
4. **The future Trainer Central "Create a Workout / Program" web page** that mimics the sheet.

**When any one of them changes (a new set type, a new exercise field, a new program type, a
rename, a removed option…), update all of them in the same piece of work:**
- edit the constants / columns in `build-workout-template.mjs`, re-run it, and bump
  `TEMPLATE_VERSION` if the layout changed (the importer must accept the old version or say
  clearly that the sheet is out of date);
- update the importer and the web page;
- tell Will the Google Sheets copy needs re-uploading.

Where the app's options live (keep the template's lists equal to these):
- Set types: `client/src/components/ExerciseCard.jsx` `SET_TYPES` (value ↔ label).
- Program types: `programs.program_type`; labels in `client/src/pages/Workouts.jsx` (`TYPE_DISPLAY`).
- Exercise library: `exercises` table, `NOT is_custom AND NOT hidden_from_library`
  (re-run the generator to refresh the Exercise Library sheet when the library changes).
- Template exercise columns: `template_exercises` (`server/schema.sql` + `initDb.js`): `exercise_id`,
  `name`, `set_type`, `set_number`, `planned_reps`, `suggested_weight`, `rep_range`,
  `program_notes`, `is_section_header`, `section_notes`, `sort_order`.
- Supersets: `supersetLabel` (A1, A2…) exists only in a session's `workout_data` today (set in
  the workout session screen). **Templates have no superset column yet** — the importer step must
  add one (e.g. `template_exercises.superset_label`) and have sessions start from it.
- Programs: 7 templates per week, rest days are `isRest` templates (week count = templates / 7).

## Decisions (2026-10-11)

| # | Question | Decision |
|---|---|---|
| 1 | Macros for green/red sheets? | **No macros.** Formulas + conditional formatting only (VBA doesn't run in Google Sheets; Apps Script would need a scary "unverified app" prompt and not work in Excel). Each sheet has a green "FILL OUT" / red "NOT NEEDED" banner, and the Start sheet lists every sheet in green/red. Tab colors can't change automatically. |
| 2 | Program layout | **Workout sheets + weekly grid.** 12 "Workout N" sheets (each distinct workout written once) + a Schedule sheet: Week 1–52 × Day 1–7, each cell a workout name or REST. |
| 3 | Sets entry | **Row per set group:** Exercise, Set Type, Sets, Goal Reps, Goal Weight. Consecutive rows of the same exercise = one exercise in the app. Sets/reps/weight are the GOAL columns, not actuals. |
| 4 | Exercise list | Live library pulled from the production DB (read only, approved). 318 exercises on 2026-10-11. Library dropdown + separate Custom Exercise and Custom Muscle Group columns. |

## Layout (v1) — what the importer reads

- **Start**: C4 Single Workout | Program; C5 program name; C6 description; C7 program type
  (label); C8 weeks; C9 number of different workouts; C10 created by.
- **Workout 1–12**: C3 workout name, H3 workout notes; exercise rows 7–56: B Section Header,
  C Library Exercise, D Custom Exercise, E Custom Muscle Group, F Superset letter, G Set Type
  (label; blank = Regular, or Super Set when F is set), H Sets, I Goal Reps, J Rep Range,
  K Goal Weight (lbs), L Coach Notes, M Check (formula). Hidden O1 = FILL/SKIP, O2 = problem count.
- **Schedule**: rows 6–57 = weeks 1–52, B–H = Day 1–7 (workout name or REST), I Check.
- **Exercise Library**: A ID, B Exercise, C Muscle Group, D Demo Video.
- **Lists** (hidden): dropdown sources, label ↔ key maps, J2 = template version.
- Importer should only trust the data cells, not the Check formulas, and re-check everything.
